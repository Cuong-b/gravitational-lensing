# Memory.md — Working Notes for gravitational-lensing

A running, editable notepad for things learned while working in this repo: preferences,
patterns, and decisions that come up during day-to-day work but don't rise to the level of
CLAUDE.md (which holds the stable, load-bearing repo rules). Keep this lightweight — only
things that are actually useful to remember next time.

**How to use this file**
- When a preference or pattern gets established or confirmed in a session, add a line for it
  under the right heading.
- If a new preference conflicts with one already logged here, don't silently overwrite it —
  ask Cuong which one should stick, then replace the old line with the resolved one.
- Prune entries that go stale or that get formalized into CLAUDE.md instead.
